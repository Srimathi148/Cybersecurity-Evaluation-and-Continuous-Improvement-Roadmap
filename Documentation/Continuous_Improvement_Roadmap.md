
# Cybersecurity Continuous Improvement Roadmap

## Organisation
Apex Technologies Pvt. Ltd. – Hypothetical Organisation

## Purpose
This roadmap defines proposed short-, medium- and long-term activities to strengthen the organisation's cybersecurity programme through regular evaluation and continuous improvement.

## Phase 1: Short-Term (0–3 Months)

| Activity | Expected Outcome |
|---|---|
| Review existing cybersecurity policies | Identify outdated or missing policies |
| Assess MFA and access control coverage | Identify account security gaps |
| Review endpoint monitoring and security alerts | Improve visibility into security events |
| Conduct employee awareness training | Improve cyber hygiene |
| Establish baseline cybersecurity KPIs | Create measurable starting points |

## Phase 2: Medium-Term (3–6 Months)

| Activity | Expected Outcome |
|---|---|
| Improve vulnerability remediation processes | Reduce unresolved security weaknesses |
| Conduct incident response tabletop exercises | Improve incident readiness |
| Perform backup restoration testing | Validate recovery capability |
| Introduce monthly KPI reviews | Track security performance |
| Review third-party security risks | Improve supplier risk management |

## Phase 3: Long-Term (6–12 Months)

| Activity | Expected Outcome |
|---|---|
| Conduct annual cybersecurity programme assessment | Evaluate overall programme effectiveness |
| Review security policies and procedures | Maintain policy relevance |
| Improve threat intelligence monitoring | Strengthen awareness of emerging threats |
| Evaluate security tool effectiveness | Identify opportunities for improvement |
| Review and update the risk register | Maintain accurate risk prioritisation |

## Continuous Improvement Cycle

1. Plan: Identify security gaps and define improvement objectives.
2. Do: Implement approved corrective actions.
3. Check: Measure results using KPIs, audits and reviews.
4. Act: Standardise successful improvements and address remaining gaps.

## Success Measurement

Progress should be measured using:

- KPI performance against approved targets
- Reduction in overdue high-risk vulnerabilities
- Improved incident detection and response
- Increased employee security awareness
- Successful backup restoration tests
- Timely closure of corrective actions

## Governance

The Security Coordinator should monitor progress, while the IT Support Team implements assigned technical improvements. Management should review significant risks, approve resources and oversee programme effectiveness.

## Disclaimer

This is a proposed 12-month academic roadmap for a hypothetical organisation. Activities and outcomes are recommendations, not claims of completed implementation.
