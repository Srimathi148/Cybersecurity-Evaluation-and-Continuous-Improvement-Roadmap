# Cybersecurity Evaluation and Continuous Improvement Roadmap

## Project Overview

This project presents a cybersecurity evaluation framework and continuous improvement roadmap for a hypothetical organisation, Apex Technologies Pvt. Ltd., with approximately 75 employees and a four-member IT support team.

The objective is to evaluate the effectiveness of cybersecurity policies, security controls, employee awareness initiatives and incident response capabilities through measurable performance indicators and periodic reviews.

## Key Areas Covered

- Cybersecurity evaluation methodology
- NIST Cybersecurity Framework 2.0 and relevant security guidance
- 22 cybersecurity Key Performance Indicators (KPIs)
- KPI formulas, targets and worked examples
- Risk assessment and prioritisation
- Security evidence collection and handling
- Periodic monitoring and review schedules
- Continuous improvement using the Plan-Do-Check-Act (PDCA) cycle
- Short-, medium- and long-term improvement roadmap
- Threat intelligence and emerging technology evaluation
- Roles and responsibilities using a RACI matrix
- Cybersecurity performance dashboard
- Recommendations and expected outcomes

## Main Deliverable

**Cybersecurity_Evaluation_and_Continuous_Improvement_Roadmap.docx**

The Word report contains the complete evaluation framework, KPI catalogue, risk assessment, review methodology and continuous improvement roadmap.

## Organisation Profile

- Organisation: Apex Technologies Pvt. Ltd.
- Location: India
- Employees: Approximately 75
- IT Support Team: 4 members

## Disclaimer

This project is an academic research and planning exercise based on a hypothetical organisation. The metrics, examples, targets and implementation roadmap are illustrative proposals and do not represent actual production security measurements or completed deployments.

## Objective

To demonstrate how an organisation can measure cybersecurity performance, identify weaknesses, evaluate security controls and continuously improve its security programme.
